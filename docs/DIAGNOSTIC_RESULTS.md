# FeMLoc V1 迁移诊断

## 范围与状态

V1自然条件130组结果保持不变。已完成全部已有权重诊断、两个源任务各100轮梯度重放、8源楼层AE学习率及步数对照。源域内部定位对照及有界外层学习率对照均已完成。

## 已确认的问题

原AE设置(.0095/200)在两个首批目标support和8源楼层上产生恒零decoder输出。两个目标分别重建MSE=.020680/.016925，与恒零基线一致，差于逐AP均值基线.014057/.009964。重放encoder与保存第0步权重一致，排除了诊断重建了另一套初值的情况。

这属于当前实现中Sigmoid decoder、稀疏零输入、初始化及优化设置组合的失败；不能归因为FeMLoc论文算法必然失败。仅靠AE loss从约.21下降到.02无法判定特征学习有效。

固定target E/M，只把共享G初值换成训练权重，会引起实际预测变化。以下为65组简单平均，用于功能诊断，不替代正式建筑等权指标：

| task | query平均预测位移 | query误差变化(训练G−初始G) |
|---|---:|---:|
| T1 | 9.2524 | 4.0416 |
| T2 | 7.3634 | 3.8605 |

因此，小参数位移不等同于零函数贡献。第0步随机mapper、饱和AE对应的大尺度latent也会放大权重微小差异；误差变大不代表共享G在正常表示下必然无用。

## 当前判断与后续边界

1. 确认原AE发生decoder全零饱和，修正AE解决了这个重建失败，并降低了开发任务早期定位误差。
2. 仅修正AE并不足以显著降低500步误差；外层lr=.01在此开发任务上进一步改善MI，.1并非更好。
3. 按500步误差，当前较好候选是AE=.0001/2000、outer=.01，但它尚未经过多个开发楼层/重复和正式目标验证，不替换V1默认配置。
4. 不能称AE故障是全部泛化误差的唯一原因；即使当前较好候选，500步仍未超过同support/query的WKNN。
5. 不进入Set/GNN改造，不自动重跑130组，不根据B2结果调整设置。下一次扩大评估应先冻结候选，再考察源域内部其他留出任务/重复。
