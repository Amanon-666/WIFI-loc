## 结论与局限

- 当前固定配置下，WKNN 的总体平均误差最低。FeMLoc 优于这两种 MLP 基线，但不能据此归因于元训练。
- T1 中 FeMLoc 与 FeMLoc-RI 几乎相同；T2 中 FeMLoc 仅有约0.160的平均改善。当前实验没有显示出明显的元训练收益，不宣称统计显著。
- MLP-FT 比 Scratch 有改善，但总体仍较差，尤其 T2 重复波动大。原因尚未核验，不能直接归结为某一网络组件或数据因素。
- 这是 FeMLoc-style 重实现与 UJI few-shot 任务改造，不是原论文数值复现。未按目标 query 选择最佳步数或追结果调整参数。
- 仅完成自然条件 N。未输入 User/Phone/Time 不等于已消除它们的影响；C-F/C-B 受控补充尚未实现，时间适应不在本批范围。
- Query 为固定位置集合，五次重复不是五个独立数据集。30条support训练较大私有编码器的风险仍需后续分析，不能由本表断言其原因。
